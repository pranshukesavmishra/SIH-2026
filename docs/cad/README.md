# ZeroDrift Mk3 — CAD

Parametric models of the build, written in OpenSCAD (free,
[openscad.org](https://openscad.org)) so they are text, diffable, and
regenerate from one source rather than being a binary someone has to
trust.

| File | What it is |
|---|---|
| `parts_lib.scad` | One module per BOM item, drawn at its real catalogue size |
| `zerodrift_full_assembly.scad` | Places those parts: rig, bench electronics, beacon, decoy |
| `zerodrift_gimbal.scad` | The earlier gimbal-only model, kept for the encoder detail |
| `renders/` | Rendered views, regenerated by the commands below |
| `*.stl` | Meshes for viewing or import; **see the printing warning** |

## Regenerating

```sh
xvfb-run -a openscad -D 'view="all"'     -o renders/01_full_scene.png       --imgsize=2200,1400 --autocenter --viewall zerodrift_full_assembly.scad
xvfb-run -a openscad -D 'view="rig"'     -o renders/02_rig.png              --imgsize=1600,1300 --autocenter --viewall zerodrift_full_assembly.scad
xvfb-run -a openscad -D 'view="head"'    -o renders/03_head_detail.png      --imgsize=1500,1150 --autocenter --viewall zerodrift_full_assembly.scad
xvfb-run -a openscad -D 'view="explode"' -o renders/04_exploded_labelled.png --imgsize=1700,2000 --autocenter --viewall zerodrift_full_assembly.scad
```

## Do not print the structural standoff

The STLs are for **viewing and fit-checking**, not for printing every
part. The head standoff specifically must be an **M3 brass standoff**
from the assortment already on the BOM. Printed in PLA at the 42 mm
length this build uses, carrying ~80 g of head:

| Material | Static droop | Natural frequency |
|---|---|---|
| Steel | 54 µrad (0.5 px) | 404 Hz |
| Aluminium / brass | 158 µrad (1.4 px) | 237 Hz |
| **PLA** | **3,109 µrad (28.5 px)** | **53 Hz** |

53 Hz sits on the 47 Hz platform mode `scenarios/ps26169_benchmark.yaml`
injects. A printed standoff is a resonator tuned to the disturbance the
whole design exists to reject.

## What building the model caught

Drawing the parts at real size next to each other surfaced four things
that reading the BOM did not:

1. **The 830-point breadboard does not fit on the base plate.** It is
   165 mm; the 6″ acrylic is 152.4 mm. It belongs on the bench beside
   the rig — which is better practice anyway, since §2E deliberately
   vibrates that plate and the control electronics are the last thing
   that should ride it.
2. **A 32 mm webcam PCB does not fit a 30 mm-tall box.** The head is
   72 × 46 × 42.
3. **The camera has to point out of the enclosure.** An early placement
   had the lens aimed into the box's own interior.
4. **A face-mounted stepper cannot sit shaft-up on a solid plate.** The
   shaft exits the same face that bolts down, so the pan motor hangs
   underneath and the shaft passes through a clearance hole.

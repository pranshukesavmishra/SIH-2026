AI-Based Virtual Camera Tracking
for Coarse Alignment of Mobile FSOC Terminals

PS SIH26169 · ISRO · Smart Automation / Software · Team ZeroDrift, Jabalpur Engineering College

PROBLEM EXISTING

MICRO-RADIAN AIM

A laser link must stay on target while vehicles, drones and masts move.

WRONG-TARGET LOCK

Stars, glints and lamps look like the beacon, so trackers lock the wrong light.

DELAY & DROPOUTS

About 40 ms of lag plus beacon blink gaps drop the beam and force manual realignment.

PROPOSED SOLUTION

We propose ZeroDrift: software that finds the partner terminal’s 4 Hz beacon in a camera image, proves it is the right light, and steers the terminal to keep it centred. It answers PS SIH26169 with an ordinary camera and no special sensor.

PHYSICS-TRUE VIRTUAL CAMERA

SGP4 orbits, turbulence and decoys, tested before hardware.

DETECT

Top-hat, matched filter, CFAR, sub-pixel centroid.

IDENTIFY

4 Hz blink test + neural verifier: 0 / 64 wrong-light locks.

TRACK & COAST

IMM Kalman filter holds through blinks: 97.5% median lock retention.

UVP · UNIQUE VALUE PROPOSITION

IDENTIFY, NOT BRIGHTNESS

Locks only on the 4 Hz blink signature.

DELAY-CANCELLED LOOP

Error is read from the image; a Smith predictor cancels the lag.

ONE ENGINE, THREE INPUTS

Simulation, webcam and terminal run the same code.

MEASURED, NOT CLAIMED

Every number is from a logged run. 250 / 251 tests pass.
